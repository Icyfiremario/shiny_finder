# Shiny finder

## About
Generates a CSV of every shiny PID for a given gen 3 TID/SID.

I made it because I found using Pokefinder to find shiny PIDs for gen 3 ACE was annoying and difficult.

## Usage
-t: TID (default: 0)

-s: SID (default: 0)

-o: Output file name (default: TSV.csv where TSV = (TID ^ SID) >> 4)

-m: Method (default: METHOD1 (ie: Static1/Wild1))
